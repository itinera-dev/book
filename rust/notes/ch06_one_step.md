In Rust, a step is a struct and an `impl` block. Deriving `Step` makes each field marked `#[input]` an input, named after the field. The `#[step]` attribute on the block declares `run`, which takes the step by value and returns `Result<Outcome, Error>`; `Self::succeed()` and `Self::fail(...)` build the outcome. A step whose `run` is an `async fn` is asynchronous, and runs only in a workflow declared `asynchronous`, on the asynchronous executor. A synchronous step in an asynchronous workflow, or the reverse, does not compile.
