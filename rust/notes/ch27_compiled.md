In Rust, every violation the builder's `build()` would report is a compile error in a workflow declared with `#[workflow(...)]`, together with a few mistakes of the attributes themselves, such as a workflow without steps. Some of the messages say "evaluation panicked": the check runs in a constant the compiler evaluates, so it is still a compile error, and nothing panics when the program runs. The rules the Rust crate makes impossible to write are listed in its `conformance.json`: a role not provided, a mode not accepted, a lifecycle a hook may not return, a non-value in the data bag, an event or a reason's details, a handle used after its attempt, and a write through an input adapter's access to the data bag.
