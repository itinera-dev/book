In Rust, every violation the builder's `build()` would report is a compile error in a workflow declared with `#[workflow(...)]`, together with a few mistakes of the attributes themselves, such as a workflow without steps. Some of the messages say "evaluation panicked": the check runs in a constant the compiler evaluates, so it is still a compile error, and nothing panics when the program runs. A lifecycle a hook may not return is a type error: each hook's return type lists only the lifecycles that hook may return. `on step failure` returns a `Result<Option<FailWorkflow>, Error>`, and `Self::finish_workflow()` gives a `Result<Option<OnSuccess>, Error>`, the return type of `on step success`, the only hook that may return `FinishWorkflow`; the types do not match, which is what the message says. The rules the Rust crate makes impossible to write are listed in its `conformance.json`: a role not provided, a mode not accepted, a lifecycle a hook may not return, a non-value in the data bag, an event or a reason's details, a handle used after its attempt, and a write through an input adapter's access to the data bag.
