Everything here is declared with Itinera's macros, which check the declarations when the program compiles. `#[derive(Step)]` makes each field marked `#[input]` an input of the step, and `#[step]` declares its `run`. `#[step_policy]` declares a policy, and `#[on_step_retry]` marks the method that is its retry hook. `#[workflow]` declares the workflow, with one `#[with_step(...)]` line per step, in the order they run; `retry_budget = 1` lets shipping be tried once more, and `policies = [Fallback]` attaches the policy. `#[derive(InitialData)]` and `#[derive(Output)]` turn plain structs into the journey's initial data and into what you read back.

To run it yourself, run `cargo run --example quick_start` in the book's `rust` directory. To use Itinera in your own project, see [Installing Itinera](../../chapters/05-installing-itinera.md).
