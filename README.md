# The Itinera book

A book about [Itinera](https://github.com/itinera-dev/spec), a workflow framework that keeps business rules separate from flow control, written for several languages. You pick the language you build with, and read the whole book in it, with examples that compile and run.

## Status

Not published yet. The first edition will be for Rust, with [itinera-rs](https://github.com/itinera-dev/itinera-rs). Once published, the book is read at <https://itinera-dev.github.io/book/>; [site/](site/README.md) builds those pages.

## Who it is for

People building software for others with Itinera, and the AI agents doing that work with them. It explains why Itinera keeps flow decisions out of business code, and shows how to write steps, workflows and policies, run them, observe them and test them. It is not a reference manual: the [specification](https://github.com/itinera-dev/spec) defines what Itinera does, and each language's API reference documents every item.

## What is here

- [BOOK.md](BOOK.md): what the book contains and how it is written, the same for every language.
- [AGENTS.md](AGENTS.md): the working manual for anyone, human or agent, working in this repository.
