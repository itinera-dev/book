In Rust, an input adapter is a method of the workflow, in an `impl` block marked `#[workflow]`, with `#[input_adapter(steps = ["charge"])]`. It is named after the method unless `name = "..."` is given. It takes `&self`, so it can use the workflow's own fields, and each further parameter says what it asks for: `#[key]` with `&str`, `#[step_name]`, `#[from_workflow]`, `#[journey_id]`, or `#[data_bag]` with `DataBagAccess<'_>` for read-only access. It returns `Result<Option<AnyValue>, Error>`: `Ok(None)` leaves the input to the data bag, and `Err` stops the step from being built. Since `AnyValue` can hold any value, a value of the wrong type is caught only during the journey, with `wrong type`.

Attaching an adapter to a step the workflow does not list, or two adapters to one step, does not compile.
